# Tasks for Today Management System

A beginner-friendly Laravel application that displays today's tasks, lists all
tasks, and shows one demo user profile. The project reuses the records from the
TSA1 CodeIgniter activity.

## Requirements

- PHP 8.2 or newer
- Composer
- SQLite support enabled in PHP

This project uses Laravel 12.

On this computer, PHP 8.2.12 is installed at
`C:\xampp\php\php.exe`, but PHP and Composer are not on `PATH`. Install Composer
and add the PHP folder to `PATH`, or use the full PHP executable path when
running Artisan commands.

## Installation

From the project directory:

```powershell
composer install
if (!(Test-Path .env)) { Copy-Item .env.example .env }
php artisan key:generate
```

The `.env.example` selects SQLite at `database/tsa3.sqlite`. Create that empty
file if it does not exist, then initialize the database and sample records:

```powershell
if (!(Test-Path database/tsa3.sqlite)) { New-Item -ItemType File database/tsa3.sqlite }
php artisan migrate
php artisan db:seed
```

Do not run `migrate:fresh` or `db:wipe`; they delete database tables and data.
If the database has already been migrated, skip creating the file and run the
seeder only when its data is safe to update.

## Run the application

```powershell
php artisan serve
```

Open `http://127.0.0.1:8000`.

## Routes

| URL | Page |
| --- | --- |
| `/` | Welcome page with tasks for today |
| `/tasks` | Complete task list |
| `/profile` | Demo user profile |
| `/about` | System information and developer name |

## Data

The `tasks` table stores a title, status (default `pending`), task date, and
Laravel timestamps. The `users` table stores a unique username, full name,
email, and Laravel timestamps. The seeder creates eight tasks over yesterday,
today, and tomorrow, plus one demo user. Re-running it updates the same records
instead of adding duplicates.

The application uses `database/tsa3.sqlite`. The separate
`database/database.sqlite` file was generated by the Laravel starter project
and was left untouched.

The application timezone is `Asia/Manila`. The Welcome page filters tasks to
that local date; the Task List page sorts by date and then ID.

## Project structure

- `app/Http/Controllers/` — page, task-list, and profile controllers
- `app/Models/` — Eloquent `Task` and `User` models
- `database/migrations/` — tasks and users table definitions
- `database/seeders/DatabaseSeeder.php` — original TSA1 sample records
- `resources/views/` — shared layout and four Blade pages
- `routes/web.php` — the four application routes
- `tests/Feature/TaskManagementTest.php` — page and data behavior tests

The local SQLite database, `.env`, Composer dependencies, runtime logs, and
generated frontend build files are excluded from Git.
